## 🔍 **Critères de sélection**
### Formations
- **Pertinence** : En lien avec l'enseignement ou l'informatique
- **Durée** : Minimum 3h de formation pour inclusion
- **Officielles** : Délivrées par organismes reconnus
- **Récentes** : Priorité aux formations 2020-2025

### Expériences
- **Significatives** : En lien avec les 3 expériences analysées
- **Vérifiables** : Avec contacts et références
- **Documentées** : Preuves tangibles disponibles
- **Autorisées** : Respect RGPD et droits d'image

### Publications
- **Publiques** : Accessibles et vérifiables
- **Professionnelles** : En lien avec le parcours
- **Qualitatives** : Apportant une valeur ajoutée
- **Récentes** : Priorité aux contributions actuelles

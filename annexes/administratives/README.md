## 📋 **Nomenclature des fichiers**
- Format : `type_document_organisme_annee.pdf`
- Exemple : `attestation_emploi_SopraSteria_2019.pdf`
- Tous les documents en format PDF
- Qualité de scan : minimum 300 DPI
- Lisibilité parfaite requise

## 📄 **Exigences de format**
- **Documents originaux** : Privilégier les copies certifiées conformes
- **Langue** : Documents en français ou avec traduction assermentée
- **Lisibilité** : Tous les textes doivent être parfaitement lisibles
- **Intégrité** : Documents complets, non tronqués
- **Authenticité** : Cachets et signatures visibles

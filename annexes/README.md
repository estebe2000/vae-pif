## 📂 **Organisation des dossiers**

```
annexes/
├── pedagogiques/          # Annexes liées aux pratiques pédagogiques
│   ├── sequences/         # Fiches de préparation, scénarios pédagogiques
│   ├── productions/       # Captures d'écran, extraits de projets élèves
│   └── evaluations/       # Grilles d'évaluation, outils d'assessment
├── administratives/       # Documents officiels et certifications
│   ├── diplomes/          # Copies des diplômes (DUT, BTS, CAPES, etc.)
│   ├── certifications/    # Certifications professionnelles (Microsoft, CISCO)
│   └── emploi/            # Attestations d'emploi, certificats de travail
└── justificatifs/         # Documents probants du parcours
    ├── formations/        # Attestations de formation continue
    ├── experiences/       # Preuves d'expériences professionnelles
    └── publications/      # Articles, contributions, projets publiés
```
